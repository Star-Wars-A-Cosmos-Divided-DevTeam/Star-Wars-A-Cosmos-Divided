# Tech Context

## Technologies Used
- Cosmoteer game engine and modding framework
- Rules file format for mod content definition
- Image editing software for sprite creation
- Text editors for code and documentation
- Git for version control

## Development Setup
- Standard Cosmoteer mod development environment
- Visual Studio Code with appropriate extensions
- Git repository for version control
- Project organized according to Cosmoteer modding conventions

## Technical Constraints
- Must follow Cosmoteer's rules file syntax and structure
- All assets must be compatible with Cosmoteer's rendering engine
- Performance considerations must align with existing game mechanics
- File naming conventions must be consistent with existing mods

## Dependencies
- Cosmoteer game client (base game)
- Cosmoteer modding tools and documentation
- Standard development tools (git, text editors)

## Tool Usage Patterns
- Rules files are used to define all mod content
- Assets are organized in a consistent directory structure
- Documentation is maintained alongside code and assets
- Version control is used for all changes
